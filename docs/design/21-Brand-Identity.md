- 原始透明背景

- 修改颜色

- 添加渐变

- 裁剪主体

使用 16px Logo。

使用 512px Logo。

使用 16px 或系统适配尺寸。

# 5. 产品气质


LinguaFlow 不应该像：

开发工具。

应该像：

一个每天都会打开的小助手。


用户感受：

打开：

轻松。

使用：

自然。

关闭：

无负担。


---

# 6. UI 原则


## 留白优先

不要堆叠信息。


## 卡片化

使用 Card 分割内容。


## 圆角优先

所有交互元素保持柔和。


## 内容优先

翻译内容永远高于配置。


## 隐藏复杂度

模型、Prompt、高级设置放入设置页。


首页只关注：

输入

翻译

结果
