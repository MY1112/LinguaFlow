# LinguaFlow Design System v1.0


# 1. 设计语言


设计体系：

Soft Fluent Design


设计目标：

打造一个柔和、安静、高效的本地 AI 翻译工具。


视觉关键词：

- 柔和 Soft
- 简洁 Clean
- 轻量 Lightweight
- 专注 Focus
- 自然 Natural


禁止：

- 过度科技感
- 大面积渐变
- 玻璃拟态
- 强阴影
- 高饱和背景
- 密集信息布局



--------------------------------------------------

# 7. 阴影规范


使用柔和阴影。


## Card Shadow


参数：

透明度低


用途：

Card轻微浮起效果。



推荐：

0 4px 16px rgba(0,0,0,0.05)



## Popup Shadow


比 Card 稍强。


推荐：

0 8px 24px rgba(0,0,0,0.10)



禁止：

明显黑色阴影。

# 16. 状态反馈


所有耗时操作必须提供状态。


例如：


模型加载：

绿色圆点

Model Ready


翻译中：

Loading状态


失败：

Error提示



禁止：

直接显示英文异常：

"No model loaded"



用户提示必须自然化。



--------------------------------------------------


# 17. 空状态设计


不要显示：

暂无数据


推荐：

友好提示。


例如：

输入框：

"请输入想翻译的内容..."


历史记录：

"还没有翻译记录"



--------------------------------------------------


# 18. UI实现原则


所有UI必须：

1. 遵循本设计系统

2. 不自行增加颜色

3. 不自行定义新的圆角

4. 不自行设计组件

5. 新组件必须先补充规范
