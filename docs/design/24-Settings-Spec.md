# LinguaFlow Settings Specification v1.0


# 1. 页面定位


Settings 是 LinguaFlow 的高级配置中心。


主要职责：

- 用户偏好配置
- 快捷键配置
- 模型管理
- 系统行为设置


原则：

默认简单。

高级功能隐藏。



--------------------------------------------------


# 2. 页面入口


入口：

MainWindow 右下角设置按钮。


Icon：

Settings


点击：

打开独立设置窗口。

# 5. General 常规设置


包含：


## 开机启动


组件：

Switch



默认：

关闭



说明：

启动 Windows 时自动运行 LinguaFlow。



---

## 启动后隐藏到托盘


Switch


默认：

开启



说明：

启动后不显示主窗口。



---

## 自动检查更新


Switch


默认：

开启

# 6. Translation 翻译设置


## 默认翻译方向


Select


选项：


中文 → English


English → 中文



默认：

中文 → English



---

## 自动复制结果


Switch


默认：

关闭



开启后：

翻译完成自动复制。



---

## 显示原文


Switch


默认：

开启



Popup中显示原文。
