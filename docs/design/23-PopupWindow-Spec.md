# LinguaFlow PopupWindow Specification v1.0


# 1. 页面定位


PopupWindow 是 LinguaFlow 最核心的快捷翻译体验。


使用场景：


用户：

选中文字


↓

按：

Alt + Q


↓

Popup 显示翻译结果



Popup 不承担输入功能。


只负责：

快速反馈翻译结果。


--------------------------------------------------


# 2. 触发流程


完整流程：


用户选中文字

↓

HotkeyAdapter 捕获 Alt + Q

↓

SelectionAdapter 获取选中文本

↓

TranslationFeature 执行翻译

↓

PopupWindow.show_result()

↓

显示翻译结果



--------------------------------------------------


# 3. 快捷键规范


默认快捷键：


Alt + Q



用途：

快速翻译选中文本。



要求：

- 全局快捷键
- 支持 Windows
- 支持注销
- 支持未来自定义



禁止：

Popup 内处理快捷键。


快捷键生命周期：

Application 管理。



--------------------------------------------------


# 4. Popup窗口规格


窗口类型：


无边框窗口。



属性：


Always On Top


保持置顶。



Focus：

不抢占用户当前输入焦点。



Taskbar：

不显示。



关闭方式：

自动隐藏。

# 12. 失败场景


如果：

没有选中文字


显示：


未检测到选中文本。

模型未加载


显示：


模型正在准备，请稍候。



如果：

翻译失败


显示：

翻译失败，请稍后重试。
