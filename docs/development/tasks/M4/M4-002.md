# M4-002 全局快捷键

## 目标

实现应用级全局快捷键。

用户无论当前焦点位于哪个程序，都可以通过快捷键唤起 LinguaFlow。

---

## 功能

实现：

- 注册全局快捷键
- 默认快捷键：
  Alt + Q
- 按下快捷键后：
  - 如果窗口隐藏，则显示窗口
  - 如果窗口已显示，则激活窗口并置顶

暂不实现：

- 自定义快捷键
- 多个快捷键
- 快捷键冲突处理

---

## 目录

新增：

src/integrations/hotkey.py

---

## 调用关系

Application

↓

HotkeyAdapter

↓

MainWindow

HotkeyAdapter 不允许直接调用 Feature。

---

## 行为

程序启动：

自动注册默认快捷键。

程序退出：

自动注销快捷键。

快捷键触发：

调用 MainWindow.show()

MainWindow.raise_()

MainWindow.activateWindow()

---

## 日志

记录：

禁止 print()

## Definition of Done

完成后：

- 默认快捷键可正常触发
- 隐藏窗口可恢复
- 已显示窗口可激活

- Ruff 通过
- Black 通过

## Integration 开发规范

1. integrations 目录仅负责与第三方系统或操作系统交互。
2. Integration 不包含业务逻辑。
3. Integration 不允许调用 Feature。
4. Integration 不允许直接操作 Runtime。
5. Integration 的生命周期由 Application 统一管理。
