# M4-001 后台推理

## 目标

将模型推理从 UI 线程迁移到后台线程执行。

保证推理过程中界面不会卡顿，不会出现"未响应"状态。

---

## 功能

实现：

- 后台线程执行翻译
- UI 保持响应
- 推理完成后自动更新译文
- 推理失败后弹出错误提示

暂不实现：

- 取消翻译
- 多任务并发翻译
- 翻译队列
- 进度条

---

## 调用关系

```
MainWindow

↓

TranslationWorker（后台线程）

↓

TranslationFeature

↓

PromptService

↓

ModelService
```

MainWindow 不允许直接创建线程执行模型推理。

统一由 TranslationWorker 负责后台执行。

---

## 目录

新增：

```
src/ui/workers/translation_worker.py
```

---

## TranslationWorker

职责：

负责后台执行：

```python
TranslationFeature.translate(...)
```

完成后发送：

成功：

```
finished(result: str)
```

失败：

```
failed(message: str)
```

不得直接操作 UI 控件。

---

## MainWindow

点击：

翻译

执行：

启动 TranslationWorker

立即：

- 禁用翻译按钮
- 禁止重复点击

收到：

finished：

- 更新译文
- 恢复按钮

收到：

failed：

- 弹出错误提示
- 恢复按钮

整个过程中：

窗口必须保持响应。

## 日志

记录：

- 后台翻译完成
- 后台翻译异常

禁止 print()

---

## Out Of Scope

本任务禁止实现：

- OCR
- Clipboard
- Hotkey
- History
- 多线程池
- 多任务翻译
- 模型切换

---

## Definition of Done

完成后必须满足：

- 推理期间窗口不卡顿
- 可以拖动窗口
- 可以最小化窗口
- 翻译完成自动更新 UI
- 翻译失败恢复按钮
- 禁止重复点击翻译
- Ruff 通过
- Black 通过
- Python 语法检查通过
- python -m src.main 启动通过
