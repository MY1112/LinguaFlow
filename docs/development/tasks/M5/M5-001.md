# M5-001 SelectionProvider

## 目标

实现获取当前系统选中文本。

为后续划词翻译提供基础能力。

---

## 功能

实现：

- 获取当前选中文本
- 返回字符串

暂不实现：

- 自动翻译
- OCR
- Popup
- Clipboard 监听

---

## 目录

新增：

src/integrations/selection.py

---

## 接口

SelectionAdapter

提供：

get_selected_text() -> str

返回：

成功：

返回选中文本。

失败：

返回空字符串。

不得抛出异常导致程序退出。

---

## 行为

默认流程：

用户：

选中文本

↓

调用：

SelectionAdapter.get_selected_text()

↓

返回：

字符串

## 实现说明

SelectionAdapter 的职责是：

提供统一的：

get_selected_text() -> str

接口。

SelectionAdapter 不保证必须使用某一种 Windows API。

允许根据不同平台和场景采用不同实现，例如：

- UI Automation
- Accessibility API
- Clipboard（模拟 Ctrl+C）

调用方不得依赖具体实现

当前版本：

Windows 默认实现：

Ctrl+C + Clipboard

后续：

允许增加 UIAutomation 实现。
