1. RuntimeManager.initialize() 负责读取 ConfigService 中的 model_path。
2. 如果 model_path 存在且文件存在，则调用 ModelService.load_model()。
3. 如果未配置 model_path 或文件不存在，不抛出异常导致程序退出，仅记录错误日志。
4. Application 不直接读取模型路径，不直接调用 load_model()。
5. RuntimeManager.shutdown() 保持负责释放模型资源。
6. 默认模型路径使用相对路径：
   models/qwen2.5-3b-instruct-q4_k_m.gguf
