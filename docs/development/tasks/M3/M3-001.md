# M3-001 TranslationFeature

## 目标

实现 LinguaFlow 的第一个业务功能：文本翻译。

TranslationFeature 负责协调 PromptService 和 ModelService，实现完整的翻译流程。

它是 UI、快捷键、OCR、剪贴板等入口统一调用的业务层。

---

## 职责

负责：

- 接收翻译请求
- 校验输入内容
- 调用 PromptService 构建 Prompt
- 调用 ModelService 执行推理
- 返回翻译结果

不负责：

- 模型加载
- Prompt 管理
- OCR
- 截图
- 剪贴板
- UI

---

## 对外接口

至少提供：

```python
translate(
    text: str,
    source_language: str,
    target_language: str,
) -> str
```

返回：

```
翻译后的字符串
```

---

## 业务流程

```
接收翻译请求

↓

校验输入

↓

PromptService 构建 Prompt

↓

ModelService.generate()

↓

返回翻译结果
```

---

## 输入校验

需要校验：

- 输入不能为空
- 输入不能全部为空白字符
- source_language 不能为空
- target_language 不能为空
- source_language 与 target_language 不能相同

校验失败时：

抛出：

```
TranslationError
```
