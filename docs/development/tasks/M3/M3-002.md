# M3-002 MainWindow

## 目标

实现 LinguaFlow 第一版翻译窗口。

用户可以输入文本，点击翻译，并查看翻译结果。

本阶段仅实现最基础的翻译界面。

---

## 功能

实现：

- 原文输入框
- 译文输出框
- 翻译按钮

暂不实现：

- OCR
- 截图
- 快捷键
- 历史记录
- 设置
- 模型切换
- 系统托盘菜单扩展

---

## 行为

点击：

翻译

执行：

TranslationFeature.translate()

成功：

更新译文文本框。

失败：

弹出错误提示。

---

## UI 要求

输入框：

支持多行。

输出框：

只读。

按钮：

翻译过程中禁用。

完成后恢复。

---

## 翻译方向

界面顶部增加翻译方向选择。

第一版仅支持：

- 中文 → English
- English → 中文

点击翻译时：

根据当前选择调用：

TranslationFeature.translate(
    text,
    source_language,
    target_language,
)
